# Материалы для сторов

Как готовить и заливать всё, что видит игрок на странице игры в сторе. Пока описан только Google Play.

Всё, что меняет страницу в Play, — действие наружу: заливать только после подтверждения пользователя.
Сначала запускать без `--apply`: скрипты только сверяют и ничего не меняют.

## Google Play

Пакет приложения скрипты берут из `game.project` (`[android] package`), имя игры для текстов — оттуда же
(`[project] title`).

```
stores/googleplay/
  listing/<язык>/title.txt              название, до 30 символов
  listing/<язык>/short_description.txt  краткое описание, до 80
  listing/<язык>/full_description.txt   полное описание, до 4000
  screenshots/<язык>/<N>_<имя>.png      скриншоты телефона, от 2 до 8, порядок по N
  icon.png                              иконка, PNG 512x512 с альфа-каналом, до 1 МБ
  feature_graphic.png                   PNG 1024x500 без альфа-канала, до 1 МБ
  whatsnew/whatsnew-<язык>              «Что нового» для релиза
```

`<язык>` — язык страницы в Play (`en-US`, `ru-RU`, …). Папки `listing` задают, какие языки есть у страницы.
Папку скриншотов можно назвать коротким кодом (`ru`), если такой язык в `listing` один.

### Тексты

Пишутся вручную, у каждого языка все три файла. Описывать только то, что реально есть в игре (сверять с кодом
и документацией проекта), без обещаний будущих функций. Новый язык = папка `listing/<язык>` с тремя файлами.

### Скриншоты, иконка и feature graphic

Делаются любым способом, важны только формат и имена файлов выше. Скриншоты — из самой игры, без текста
поверх интерфейса, подписи — над кадром. Иконка — та же, что у приложения (`[android]` иконки в `game.project`), в 512x512; углы Play скругляет сам.
Feature graphic без мелкого текста: Play обрезает её на части экранов. Иконка и feature graphic — одни на все языки.
Если в проекте есть свои инструменты (например, `tools/store_shots/`), смотреть их описание в начале скриптов.

### Заливка страницы: `scripts/fun.sh store/gp_listing`

```bash
scripts/fun.sh store/gp_listing                         # сверка: что отличается от Play
scripts/fun.sh store/gp_listing --apply                 # залить отличающееся
scripts/fun.sh store/gp_listing --apply --only texts    # только тексты (screenshots, icon, graphic)
scripts/fun.sh store/gp_listing --apply --lang ru-RU    # один язык
scripts/fun.sh store/gp_listing --apply --no-review     # если Play не отправляет изменения на проверку сам
```

- До запросов в Play проверяет файлы и останавливается со списком ошибок: нет файла, пустой текст,
  превышен лимит, не то число кадров, кадры без текстов своего языка, у иконки или feature graphic
  не тот размер, альфа-канал или вес.
- Меняет только то, что отличается: тексты — по полям, скриншоты — весь набор языка, сравнение по sha256.
- Языка нет на странице — добавляет его. Без своих кадров язык показывает кадры языка по умолчанию.
- Иконку и feature graphic заливает в язык страницы по умолчанию, остальные показывают их. Если у языка
  своя, другая, — заменяет.
- Всё уходит одной правкой (edit) и попадает на проверку Google.

### «Что нового»

`whatsnew/whatsnew-<язык>`, до 500 символов. Обновлять перед каждым релизом; загружается вместе со сборкой
(в CI или вручную в Play Console).

### Внутриигровые покупки: `scripts/fun.sh store/gp_products`

Сверяет товары, нужные игре (`assets/targets.json` → `googleplay.iapservice.products`,
`assets/gamedata.json` → `iapservice.lots`), с Play Console. `--apply` создаёт недостающие,
`--sync-prices` приводит цены к `usd_price`. Существующие товары не меняет.

### Ключ доступа

Сервисный аккаунт в Play Console (Users and permissions) с правом «Управление страницей приложения»; для покупок
ещё «Просмотр информации о приложении» и «Просмотр финансовых данных». Права применяются не сразу.

Скрипты ищут JSON-ключ по порядку (`tools/store/gp_common.py в FUN`):

1. `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` — путь к JSON или сам JSON (так же в CI);
2. `gp-keys.json` в корне проекта — обязательно в `.gitignore`;
3. Связка ключей macOS, запись `google-play:<пакет>` (команда добавления — в `tools/store/gp_common.py в FUN`).

Ключ не печатать, не коммитить и не просить. В git worktree файла `gp-keys.json` нет — передать путь
к файлу основного репозитория через переменную. Песочница агента может не видеть Связку ключей и файлы
вне рабочей папки — тогда запускать скрипт без песочницы.

### Подключение к проекту

Скрипты живут в FUN (`tools/store/`) и запускаются из корня проекта через `scripts/fun.sh` — той же версии,
что FUN в `game.project` (см. `tools/README.md` в FUN). В проекте лежат только данные: `stores/googleplay/`
и `gp-keys.json` (в `.gitignore`). Зависимости: python3 + `requests`, `openssl`.
